# hxyfront-62006 宝石领用柜

在原有珠宝分拣静态台账基础上改造的「宝石领用柜」前端系统。纯前端、不接后端、无外部服务依赖，存档落在浏览器 localStorage，重开页面按存档继续。

## 业务规则

- **领用确认**：高价值宝石须两名当班人员确认（不可为同一人、领石师傅本人不可当确认人）；普通宝石一名当班人员确认。
- **持有上限**：师傅名下未还的高价值宝石超过 2 颗即停领（普通石也不能再领），归还一颗后恢复。
- **保险锁柜**：保险凭证过期立即锁柜，领用一律不受理；补齐有效凭证（凭证号 + 晚于今天的到期日）后解锁。
- **归还检验**：归还复称与存档重量差异超出允差（max(0.5%, 0.002ct)），或检查发现镶口伤痕，自动转「待复核」。
- **订单结项**：关联订单存在待复核宝石时不能结项；待镶数未清零同样不能结项。
- **存档展示**：柜位、师傅持有数、订单待镶数全部按存档实时显示；领还流水全程留痕。

## 文件分工（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/business/rules.ts` | 业务规则：纯函数校验（领用 / 归还评估 / 结项 / 保险 / 持有上限），不依赖 React 与存储 |
| `src/business/storage.ts` | 持久化：localStorage 存档读写、初始演示快照、存档损坏回落 |
| `src/business/state.ts` | 页面状态：`useCabinetStore`（useReducer + 派生视图），变更前过规则、变更后落存档 |

`src/App.tsx` 只负责界面与操作入口，不含任何业务阈值。
